# M1 Blockbasierte Programmierung: Arcade Tutorials

Dieses Repository enthält benutzerdefinierte Tutorials für MakeCode Arcade. 
Sie sind Teil einer projektorientierten Unterrichtseinheit für die 7. Klasse (Hamburger Bildungsplan, Bereich M1).

Die Tutorials sind darauf ausgelegt, dass Schülerinnen und Schüler sich gezielt Wissen (z. B. über Variablen, Schleifen und Bedingungen) aneignen können, um ihre eigenen Retro-Spiele (Minimum Viable Products) zu entwickeln.
